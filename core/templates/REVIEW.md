# Review

A practical aid for STD-07 in the [standard](../standards/ENGINEERING_STANDARD.md). Scale to the change; a solo developer can review directly without a PR.

- Change/revision and reviewer: [identify actual reviewed working state].
- Correctness: [outcome and acceptance criteria met? edge cases?].
- Scope: [only authorized changes? unrelated modifications?].
- Verification: [actual results, failures, missing checks and implications].
- Material risk: [security, data, dependencies, external effects, recovery, cost as applicable].
- Maintainability: [knowledge and architecture consistent?].
- Decision: [Pending review / Accepted / Changes requested / Rejected / Not applicable; rationale].
- Follow-up: [specific actions and owner].
- Merge / release: [separate authority and evidence; no automatic inference from acceptance].
