# Roadmap and future capability proposals

## Proposed sequence

| Phase | Focus | Status |
| --- | --- | --- |
| v1.0 | Release-readiness review and bounded claims | Proposed; no release/tag |
| v1.1 | Optional adoption tooling, diagnostics, skill exposure | Proposed |
